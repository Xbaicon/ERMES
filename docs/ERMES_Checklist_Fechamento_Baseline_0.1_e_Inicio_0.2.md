# ERMES — Checklist de Fechamento da 0.1 e Início da 0.2

## Fechar Baseline 0.1

- [ ] Todas as funcionalidades previstas para 0.1 estão implementadas ou explicitamente retiradas/corrigidas por decisão formal.
- [ ] Não há trabalho parcial relevante escondido em branches/arquivos.
- [ ] Aplicação inicia sem erro.
- [ ] Testes automatizados passam.
- [ ] Smoke test manual dos fluxos principais passa.
- [ ] Auditoria requisito × código da 0.1 foi concluída.
- [ ] Correções de escopo sobre geocodificação/rotas foram consideradas.
- [ ] Nenhuma funcionalidade 0.2 foi implementada prematuramente por acidente.
- [ ] Estado do repositório está limpo ou mudanças conhecidas estão documentadas.
- [ ] Checkpoint/commit/tag da 0.1 foi criado após autorização humana.

## Preparar migração para 0.2

- [ ] Ler integralmente `ERMES_Baseline_0.2.md`.
- [ ] Ler `ERMES_Changelog_0.1_para_0.2.md`.
- [ ] Executar auditoria do Codex antes de editar.
- [ ] Identificar migrações de banco.
- [ ] Criar plano de implementação incremental.
- [ ] Implementar e testar por blocos.
- [ ] Executar suíte completa no final.
- [ ] Realizar smoke test humano.
- [ ] Comparar resultado com critérios de aceitação da 0.2.
- [ ] Só após aprovação humana criar checkpoint da 0.2.
